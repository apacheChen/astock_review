# 📈 A股复盘助手

一个装在手机上的 A 股每日复盘小工具：一键从全市场 5000+ 只股票中筛出值得留意的候选名单，附评分、星级与入选理由。

## ✨ 功能

- 🔄 **一键复盘**：全市场快照 → 常识过滤 → 流动性/质量三层漏斗 → 五维打分排序
- ⭐ **候选榜**：评分、星级、涨跌幅、技术标签一目了然
- 🔍 **详情查看**：点任意候选，看打分、入选理由与历史复盘轨迹
- 📌 **自选股**：心动的候选一键加入自选，持续跟踪
- 🕘 **复盘历史**：每次复盘自动存档，随时回看任意一次的结果
- 📴 **离线兜底**：启动自动载入最近一次结果，没网也能看榜

## 🧭 数据来源

- 东方财富公开行情接口（全市场快照）
- 可选：akshare / 通达信本地数据做补充

## 🛠 技术栈

Python + Kivy（跨平台界面）+ pandas（数据处理）+ Buildozer（打包 APK）+ GitHub Actions（云端编译）
